random-display-p3-color v2.0.0

Click anywhere to generate a new color. Zero dependencies.

Install

npm install random-display-p3-color

Usage

import randomP3 from 'random-display-p3-color'

randomP3()
// => "color(display-p3 0.93 0.18 0.45)"

randomP3({ hue: 'blue' })
// => "color(display-p3 0.12 0.38 0.95)"

randomP3({ hue: 'warm', lightness: [0.7, 0.9] })
// => "color(display-p3 0.94 0.82 0.75)"

randomP3({ format: 'object' })
// => { r, g, b, alpha, css }
