# random-display-p3-color

Generate random colors in the Display-P3 color space. Constrain by hue, saturation, and lightness. Zero dependencies.

## Install

```bash
npm install random-display-p3-color
```

## Quick Start

```js
import randomP3 from 'random-display-p3-color'

// Random P3 color
randomP3()
// => "color(display-p3 0.9312 0.1847 0.4502)"

// Random blue
randomP3({ hue: 'blue' })
// => "color(display-p3 0.1203 0.3841 0.9518)"

// Pastel warm tones
randomP3({ hue: 'warm', lightness: [0.7, 0.9], saturation: [0.3, 0.6] })
// => "color(display-p3 0.9401 0.8218 0.7512)"
```

## API

### `randomP3(options?)`

Returns a CSS `color(display-p3 r g b)` string by default.

Without options, generates three independent random floats in [0, 1] covering the entire Display-P3 gamut. When hue, saturation, or lightness constraints are provided, generates colors via HSL for precise control.

#### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `hue` | `string \| [min, max]` | Full wheel | Named hue or finite degree range in 0-360 |
| `saturation` | `[min, max]` | `[0, 1]` | Finite HSL saturation range in 0-1 |
| `lightness` | `[min, max]` | `[0, 1]` | Finite HSL lightness range in 0-1 |
| `alpha` | `[min, max]` | `[1, 1]` | Finite opacity range in 0-1. Included in output only when < 1 |
| `format` | `'css' \| 'object'` | `'css'` | Output format |
| `output` | `'css' \| 'object'` | `'css'` | Alias for `format` |

Single-value ranges such as `[0.5, 0.5]` return that exact value. Non-fixed ranges are sampled with `Math.random()`, so generated values are greater than or equal to the minimum and less than the maximum. `saturation`, `lightness`, and `alpha` ranges must be ordered as `[min, max]`. Hue ranges may wrap around zero, so `[350, 10]` means red hues from 350-360 and 0-10 degrees. Invalid ranges throw `TypeError` or `RangeError` before a color is generated.

#### Named Hues

| Name | Degrees | |
|------|---------|--|
| `'red'` | 345-360, 0-15 | Scarlets, vermilions |
| `'orange'` | 15-45 | Ambers, tangerines |
| `'yellow'` | 45-70 | Golds, lemons |
| `'green'` | 70-165 | Limes to emeralds |
| `'cyan'` | 165-195 | Teals, aquas |
| `'blue'` | 195-260 | True blues, cobalts |
| `'purple'` | 260-310 | Violets, indigos |
| `'pink'` | 310-345 | Magentas, hot pinks |
| `'warm'` | 0-70 | Red through yellow |
| `'cool'` | 165-310 | Cyan through purple |

Custom degree ranges work too:

```js
randomP3({ hue: [200, 260] }) // blue-ish
randomP3({ hue: [30, 60] })   // orange-yellow
randomP3({ hue: [350, 10] })  // wraps through red
```

## Examples

### Vibrant saturated colors

```js
randomP3({ saturation: [0.7, 1], lightness: [0.4, 0.6] })
```

### Soft pastels

```js
randomP3({ saturation: [0.2, 0.5], lightness: [0.75, 0.9] })
```

### Dark moody tones

```js
randomP3({ lightness: [0.05, 0.25], saturation: [0.3, 0.8] })
```

### Monochromatic palette

```js
const palette = Array.from({ length: 5 }, () =>
  randomP3({ hue: [200, 220], saturation: [0.4, 0.8] })
)
```

### With transparency

```js
randomP3({ hue: 'blue', alpha: [0.3, 0.8] })
// => "color(display-p3 0.12 0.38 0.95 / 0.542)"
```

### Object output

```js
randomP3({ hue: 'green', format: 'object' })
// => {
//   r: 0.2134, g: 0.8012, b: 0.3891,
//   alpha: 1, h: 130.2, s: 0.612, l: 0.507,
//   css: "color(display-p3 0.2134 0.8012 0.3891)"
// }
```

`output: 'object'` is also accepted for consistency with `random-colorjs-color`.

### Canvas / p5.js

```js
// Set fill in a canvas 2D context
const ctx = canvas.getContext('2d')
ctx.fillStyle = randomP3({ hue: 'purple' })
ctx.fillRect(0, 0, 100, 100)
```

### SVG

```html
<circle fill="color(display-p3 0.9 0.2 0.5)" r="50" cx="50" cy="50" />
```

Generate the fill value:
```js
document.querySelector('circle').setAttribute('fill', randomP3())
```

### CSS custom properties

```js
document.documentElement.style.setProperty('--accent', randomP3({ hue: 'blue' }))
```

## What is Display-P3?

Display-P3 is a wide-gamut color space that covers about 50% more colors than sRGB. It's supported on most modern Apple devices, many Android phones, and an increasing number of monitors.

CSS supports it via the `color()` function:

```css
.element {
  background: rgb(255 51 128);
  background: color(display-p3 1 0.2 0.5);
}
```

Colors generated by this package may appear more vivid than anything achievable in sRGB. For browsers that do not parse `color(display-p3 ...)`, provide a fallback declaration first as shown above; unsupported declarations are ignored by the CSS cascade.

## How It Works

- **Without constraints**: Generates three independent `Math.random()` floats in [0, 1] for r, g, b. This covers the entire P3 coordinate cube.
- **With constraints**: Generates hue, saturation, and lightness values within the requested ranges, converts HSL to RGB via the standard algorithm, and outputs the result as P3 channel values.

The package is a single file with zero dependencies.

## TypeScript

Full type definitions are included. The package exports types for `RandomP3Options`, `ColorObject`, `HueName`, and `Range`.

```ts
import randomP3 from 'random-display-p3-color'
import type { RandomP3Options, ColorObject } from 'random-display-p3-color'

const color: string = randomP3({ hue: 'blue' })
const obj: ColorObject = randomP3({ hue: 'blue', format: 'object' })
```

## Migration from v1

v2 is a complete rewrite with a new API.

```js
// v1
const randomDisplayP3Color = require('random-display-p3-color')
randomDisplayP3Color() // 6 positional params, CJS

// v2
import randomP3 from 'random-display-p3-color'
randomP3() // options object, ESM, hue constraints
```
